\# Crane Autoclicker

A Roblox Bedwars autoclicker built with Python and PySide6, using only .py and .qml files.



\## Features

\- Adjustable clicks per second (CPS)

\- Start/stop hotkey

\- Left and right mouse buttons

\- Click duty / click timing

\- Modern graphical interface

\- Presets

\- Resolution Changes

\- Left/Right/Middle Click

\- Themes, light and dark mode and UI colour changes

\- So much more



\## Installation

1\. Download the Autoclicker from gitHub.com/cr9ne/craneautoclicker

2\. Extract the downloaded ZIP file.

3\. Run `CraneAutoclicker.exe`.
